# The Demon Hunter's code

The Demon Hunter rides the shared combat engine: a skill is a spell record plus the numbers of its sheet
(`data/d3/demon_hunter_skill_values.csv`), and the engine casts, costs, hits and ticks it. The code in this folder is what a
record and a number cannot say: when, where, on whom. Contract: `docs/contracts/demon-hunter-class.md`.

`dc_demon_hunter.h` declares the seams the engine calls (`Connected`, `BasePct`, `Landed`, `Casting`, `Impact`, `Ground`, `Aim`, `CanCast`, `Cast`, `Multipliers`, `RegisterScripts`); `dc_demon_hunter.cpp` is the dispatch and pays
the Hatred every primary generates. A skill that needs code gets a file of its own when its bead lands.

## The two pools need no code

Hatred (Energy, 125, 5 a second) and Discipline (Focus, 30, 1 a second) are rows of `class_resources.csv`. The registry
(`dc_resources.h`), the stats hook (maxima, the login fill), the resource pulse (regeneration), `CostFraction` in `dc_classes.cpp` (a
cost's fraction, by the record's power), Paragon (`paragon.csv`: Hatred +0.5 a point, Discipline none) and the core's own spell
cost (a record's `PowerType` and `ManaCost`: Energy for a Hatred spender, Focus for a Discipline one) already read them.
