# The Witch Doctor's code

The Witch Doctor rides the shared combat engine: a skill is a spell record plus the numbers of its sheet
(`data/d3/witch_doctor_skill_values.csv`), and the engine casts, costs, hits and ticks it. The code in this folder is what a
record and a number cannot say: when, where, on whom. Contract: `docs/contracts/witch-doctor-class.md`.

`dc_witch_doctor.h` declares the seams the engine calls (`Connected`, `BasePct`, `Landed`, `Cast`, `Ground`, `AttackSpeed`, `Toggle`, `RegisterScripts`); `dc_witch_doctor.cpp` is the dispatch and pays the Mana
the on-hit runes return. A skill that needs code gets a file of its own when its bead lands.

## Mana needs no code

Mana (the stock slot, 750, 50 a second) is a row of `class_resources.csv`. The registry (`dc_resources.h`), the stats hook (the
maximum, the login fill), the resource pulse (regeneration, the one source: the class's mask record keeps the core's tick off),
the core's own spell cost (a record's `PowerType` 0 and `ManaCost` in points: the eight spenders pay, the four Primaries are free)
and Paragon (`paragon.csv`: +4 a point) already read it.

## The pets

The creatures are `data/d3/witch_doctor_summons.csv` (entries 900170-900173, `minions_0003`); the numbers the power files add to the
sheets are `data/tunables/witchdoctor.csv`. A pet belongs to its owner: its blows are the Witch Doctor's own `Combat::Strike`, it is
counted as no monster, gives no progress and goes on logout and floor change (the shared piece's rules).
